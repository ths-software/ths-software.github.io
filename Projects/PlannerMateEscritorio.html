PlannerMate escritorio

PlannerMate versión escritorio, es un proyecto de comercio electrónico (e-commerce) desarrollado con .NET en Visual Studio. Se trata de una aplicación de gestión de citas, empleados y clientes, en este caso, un salón de peluquería. Todo para ser manejado desde el escritorio.

Los empleados podrán revisar las citas pendientes en un cómodo calendario, añadir nuevas, editarlas y eliminarlas.

También dispone de un listado de clientes con información de contacto. Los clientes pueden registrarse en el comercio, y el empleado introduce los datos directamente en la aplicación.

En conjunto con la aplicación de Android de PlannerMate para empleados, el flujo de trabajo es más sencillo y eficiente. Desde la versión de Android, los clientes pueden agendar las citas con el profesional deseado, revisarlas y cancelarlas.

El proyecto utiliza una base de datos relacional con MySQL para almacenar la información de las citas, los clientes, incluso de sus trabajadores. Ambas aplicaciones acceden a la API REST para trabajar en conjunto.

PlannerMate versión para empleados ha sido desarrollada siguiendo las recomendaciones y buenas prácticas de desarrollo, utilizando el patrón arquitectónico ViewModel y favoreciendo una buena experiencia de usuario con una navegación ágil e intuitiva. El código tiene una estructura modular, escalable y mantenible.

Proyecto de desarrollo propio, diseñado e implementado íntegramente por mí, sin utilizar código generado por inteligencia artificial.

Tecnologías

  • C#: Lenguaje principal de la aplicación.
  • Visual Studio: IDE utilizado para el desarrollo.
  • RestSharp: Paquete REST para el consumo de la API.
  • WPF: framework de .NET utilizado para desarrollar la interfaz gráfica de la aplicación de escritorio.
  • API REST y JPA: Persistencia y acceso a datos tanto para la aplicación de Android como para la de escritorio.
  • MySQL: Base de datos.
