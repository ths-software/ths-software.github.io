PlannerMate Android

PlannerMate versión Android, es un proyecto de comercio electrónico (e-commerce) desarrollado con Kotlin en Android Studio. Se trata de una aplicación de solicitud de citas para, en este caso, un salón de peluquería. Todo desde tu dispositivo Android.

Los usuarios son registrados desde el comercio, y pueden acceder con su usuario y contraseña a la aplicación, donde podrán solicitar las citas por sí mismos, eligiendo la hora, el día y el profesional disponibles.

La aplicación permite consultar las citas pendientes para ver la hora y el día. También dispone de un apartado de configuración donde pueden introducir datos de contacto o cambiar la contraseña.

En conjunto con la aplicación de escritorio de PlannerMate para empleados, el flujo de trabajo es más sencillo y eficiente. Desde la versión de escritorio, los empleados pueden revisar las citas, hacer cambios y contactar con el cliente en caso de necesitarlo.

El proyecto utiliza una base de datos relacional con MySQL para almacenar la información de las citas, los clientes, incluso de sus trabajadores. Ambas aplicaciones acceden a la API REST para trabajar en conjunto.

PlannerMate Android ha sido desarrollada siguiendo las recomendaciones y buenas prácticas de desarrollo de Android. Utiliza el patrón arquitectónico ViewModel y componentes de navegación para organizar la aplicación, favoreciendo una estructura modular, escalable y mantenible.

Proyecto de desarrollo propio, diseñado e implementado íntegramente por mí, sin utilizar código generado por inteligencia artificial.

Tecnologías

  • Kotlin: Lenguaje principal de la aplicación.
  • Android Studio: IDE utilizado para el desarrollo.
  • Retrofit: Cliente REST para el consumo de la API.
  • Jetpack Compose: Toolkit declarativo para crear interfaces Android.
  • API REST y JPA: Persistencia y acceso a datos tanto para la aplicación de Android como para la de escritorio.
  • MySQL: Base de datos.
