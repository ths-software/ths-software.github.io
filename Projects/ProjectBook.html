Project bookshop

Project Bookshop es un proyecto de comercio electrónico (e-commerce) y ERP desarrollado con Java y Spring Boot. Se trata de una librería online que cuenta con una parte pública, accesible para cualquier visitante, y otra privada, destinada a usuarios registrados y empleados.

Los usuarios pueden registrarse y comprar libros a través de una tienda online con carrito de compra, donde pueden añadir los libros que les interesen y comprarlos cuando lo deseen. El sistema les guía durante el proceso de compra y les permite consultar posteriormente sus pedidos y facturas.

El proyecto utiliza una base de datos relacional con MySQL para almacenar la información de los libros, gestionar su stock y guardar los datos de clientes y empleados. Además, se aplican medidas de protección para mantener seguros los datos de los usuarios.

La aplicación cuenta con un sistema de roles que permite diferenciar los permisos de clientes y empleados. Los clientes pueden comprar tantos libros como deseen, siempre que haya stock disponible. Si un libro no está disponible, se muestra un aviso en su página de producto. Por su parte, los empleados pueden gestionar el catálogo desde su cuenta administrativa, añadiendo nuevos libros, actualizando el stock y modificando los productos existentes.

Proyecto de desarrollo propio, diseñado e implementado íntegramente por mí, sin utilizar código generado por inteligencia artificial.

Tecnologías

  • Java 21: Lenguaje principal de la aplicación.
  • Spring Boot: Estructura y configuración de la aplicación.
  • Spring Data JPA: Persistencia y acceso a datos.
  • Spring Security: Autenticación y autorización de usuarios, seguridad de la aplicación.
  • Thymeleaf: Motor de plantillas para las vistas.
  • MySQL: Base de datos.
  • Bootstrap 5: Diseño responsive e interfaz.
